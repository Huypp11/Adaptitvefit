# AdaptiveFit AI

Phase 2A: backend foundation (Spring Boot + MySQL + JWT auth + profile).

## Chay
1. `cp .env.example .env` va doi cac gia tri
2. `docker compose up -d`
3. `cd backend && mvn spring-boot:run`  (chay tu thu muc backend/ de doc ../.env)
